1. Pull league events from CourtReserve

Hits /api/v1/eventcalendar/eventlist filtered to the League category. Creates a Leagues row for each event with cr_event_id set. Run this first — attendance pulls use Leagues to know which events to keep.

Advanced — manual CR registration pull / staging inspector (rarely needed since attendance is the primary source)

Pull registrations from CourtReserve

Pulls event registrations into the CR_Registrations table. Re-running is idempotent: existing rows update in place (status, partners) and assignments are preserved. Normally happens automatically when you visit a league admin page if the cache is stale.

Staged registrations

Filter the staging table client-side, then bulk-assign filtered rows to a league. Already-assigned rows are skipped by Assign.

Attendance / No-shows

Pulls check-in data from /api/v1/attendancereport/checkin, filtered to events that appear in the registrations staging table. No-shows are rows where Check-in status ≠ Checked In.

Members
